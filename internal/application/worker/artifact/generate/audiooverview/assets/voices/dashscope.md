# Instruct — 脚本侧语音控制说明

生成对话脚本时，在 `voice_instruction` 中用自然语言描述语气、语速、情绪与风格。

## 指令控制（`voice_instruction`）

用自然语言描述期望表达；可覆盖语速、情绪、语调、风格。不要写空泛词（如「正常」「好听」）。

可组合维度：语速 · 情绪 · 语调 · 声线特点 · 场景用途

```text
语速偏慢，语气沉稳，吐字清晰，适合讲解关键结论。
语速较快，带一点上扬，好奇追问的感觉。
温柔叙事，语调平和，像在讲故事。
严肃克制，略微加重数字和对比处。
轻松接话，语气自然，末句略带引导。
```

---

## 写法示例

```json
{
  "text": "想象一下，模型卡在一条很窄的巷子里。一堵，整条街都动不了。",
  "voice_instruction": "语速适中，带一点故事感，语气轻松温暖"
}
```

```json
{
  "text": "我核实过实验数据，注意力层量化后 perplexity 上升了 12%。",
  "voice_instruction": "沉稳有据，念百分比时清晰有力，语速略慢"
}
```

```json
{
  "text": "所以两边其实在争同一件事？是不是可以把分歧收敛到成本？",
  "voice_instruction": "好奇追问，末句略上扬，留一点思考空间"
}
```

---

## 使用原则

1. 语气只写在 `voice_instruction`，用自然语言。
2. 描述要具体：语速/情绪/语调至少一个维度落到实处。
3. `text` 只放对白正文，不要夹带控制标记。
4. 每轮一条指令即可，避免堆砌矛盾要求（例如又「很慢」又「很快」）。
