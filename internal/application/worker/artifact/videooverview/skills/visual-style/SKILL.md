# 视觉风格与画面质量

本技能是 `video-generate` 入口提示的知识库（位于工作目录 `skills/visual-style/SKILL.md`）。
**设计画面、画示意图、排版前读本文件**。本片配色 / 字体 / 动效由当前主题的 `skills/theme/<visual_style>/tokens.css` 提供，主题性格与构图 / 动效指引见同目录 `theme.json` 的 `guidance`；本文件讲怎么把 token 用好看、把示意图画得像。

## 通用规则

- 一套配色 = `--surface` + `--surface-2` + `--text`/`--text-2` + `--accent`，**全片不改**；中性色向强调色偏一点，不要死灰。
- 每个镜头至少一个颜色「抓住眼睛」；强调色氛围用 15–25% 透明度，焦点元素全饱和。
- 深色背景不要用全屏线性渐变（H.264 会出色带）；用径向渐变或纯色 + 局部光晕。
- 文字对比度满足 WCAG AA：正文 ≥ 4.5:1，大标题 ≥ 3:1；标题用 `--text`，勿用过浅色当正文。
- 反 AI-slop：渐变文字、左侧彩色竖条、纯黑纯白、深色底+青/紫蓝霓虹渐变、一模一样的卡片网格、所有内容居中且权重相同——出现前先确认是有意为之。

## 构图三测（每帧过一遍）

- **Squint 眯眼测**：一个主元素要比最近的次元素大 3–6×；不同时出现两个「标题级」元素（要主从，不要平权）。
- **Silence 留白测**：陈述帧读起来应有 45–60% 的空白；全片只指定**一个「密集例外」帧**（数据 / 机制帧）允许塞满；稀疏帧不要为了显得完整而填满。
- **Restraint 克制测**：稀缺手势每帧只出现一次——一个硬阴影、一档强调色、一种色调处理，不要叠加。
- 每帧写一句 Reference + 失败模式（如「投研简报风；失败 = 扁平、无边框、柔阴影的网页卡片网格」），防止自己漂回默认网页感。

## 图形语义（示意图必须「读得出来」）

没有真实素材时用抽象图形，但抽象图形也必须像它代表的东西——**形状、比例、符号、纹理承担语义**，不要靠颜色硬凑：

| 画什么 | 怎么画 |
| --- | --- |
| 屏幕 / 设备 | 设备比例 + 圆角 + 2–4px 描边 + 极淡扫描线纹理 + 内阴影；描边是信号，填充保持安静 |
| 视频 | 屏幕签名 + 居中圆环里的播放三角 |
| 图片 | 4:3 / 3:2 色块 + 偏角落（不居中）的地平线 + 圆盘符号 |
| 卡片 | 底板 + 1px 描边 + 两条不等长骨架线（100% / 62% 宽） |
| 人 / 头像 | **圆形** + 镂空首字母；多人堆叠用不同明度档，不用不同色相 |
| 品牌 / Logo | **圆角方形** + 镂空标记；一排 Logo 用同一明度档（表示「同等」） |
| 图表 | 平涂柱 / 线；主系列最实、对比系列次之、网格线用 1px 极淡描边；**柱内禁止渐变**（柱越高顶部越浅，会反向误导对比） |
| 文字块 | 圆角横线，宽度 100% / 86% / 62%，右缘参差才像文字 |
| 连线 / 箭头 | 必须能说出起点锚、终点锚和作用（揭示 / 路由 / 验证 / 强调）；说不出就删 |

明度阶梯（用 `--text`（或 `--text-2`）的透明度，全片统一）：实心内容 100% → 主体 72% → 支撑 45% → 介质填充 18% → 底板 8%（也可直接用 `--surface-2`）；1px 边界用 14%。相邻档至少差 1.6 倍；文字不低于 72% 档，需要比较的图形不低于 45% 档。圆形 = 人，圆角方形 = 品牌 / 应用，两个形状语义不要混。

- 深度不靠阴影靠层级：明度差 → 1px 描边 → 留白 → 细纹理（2–4px 周期，只用于标注「这里是媒体 / 内容」）。阴影必须无彩、扩散：`0 Npx 3Npx rgba(0,0,0,0.18)`；彩色光晕是强调色，不是阴影。
- 强调色全片最多一个元素且必须承载意义（选中的档、当前步骤、计数落点、正在画的描边）；占位图形永不用强调色。
- 禁止无物理意义的占位渐变（紫→蓝、彩虹、斜向色块）；允许的渐变只有：物理表面（设备边框 / 玻璃）、扫光（透明→白→透明）、压暗 / 晕影、以及本身就是主体的效果。
- 本片三套风格都是浅色画布：**不要转深色**；用更粗的描边（2–4px）、结构线、全饱和强调色、极淡纹理避免「空白幻灯片感」。
- 图标用基础几何（圆 / 方 / 线 / 简单 path）画，最小可辨特征 ≥ 24px；不要 emoji 充图标，不要硬凑复杂写实路径。
- **完整性**：分镜里每个具名图形，DOM 里必须真的有它的主体——说「三节点关系」就得有三个节点和连线；说「路径生长」就得有真实路径；说「翻转 / 填充 / 对撞」就得真发生。图形缺失或退化成空盒子，比不好看更严重。

## SVG 绘制纪律（图标 / 示意图）

- **原语优先**：能用 `<circle>` / `<ellipse>` / `<rect rx>` / `<line>` / `<polygon>` 就别用 `<path>`；原语不会走形，只有自由形状才用 path。
- **对称靠镜像**：先定中心与坐标网格（如 `viewBox="0 0 120 120"`、中心 60,60），左右 / 上下坐标成对镜像（左 30 右 90），不要各自估。
- **闭合**：闭合图形用 `<polygon>` 或 path 末尾写 `Z`，不要指望描边端点自己接上。
- **曲线**：圆弧用原语或 `A` 命令，禁止随手写 `C` / `S` 贝塞尔控制点。
- **描边留边**：`stroke-width` 向路径两侧各扩一半，viewBox 四周留 ≥ `stroke-width/2` 边距；出血装饰显式处理（`overflow: visible` 或容器裁切）。
- **比例**：`viewBox` 宽高比必须与显示尺寸一致，别让 CSS `width/height` 拉成不同比例，否则整体拉伸走形。
- **发丝线**：视频里 1px 线会闪 / 消失（H.264），SVG 描边 ≥2px、整数坐标。
- **端点与填充**：`stroke-linecap="round"` / `stroke-linejoin="round"` 避免 miter 尖刺；描边图形必须 `fill="none"`，空心 / 挖洞图形用 `fill-rule="evenodd"`。
- **箭头 marker**：`refX` / `refY` / `orient="auto"` 设对，否则箭头脱离线或飞出去。
- **渐变坐标**：明确 `gradientUnits`（`objectBoundingBox` vs `userSpaceOnUse`），用错位置就偏。
- **缩放保描边**：元素被 `scale` 放大时用 `vector-effect="non-scaling-stroke"` 保持描边粗细。
- **别在 SVG 里排文字**：`<text>` 不换行、字体度量与 HTML 不同，文字用 HTML 覆盖。
- **光学对齐**：不对称图形（播放三角、箭头）按视觉居中，不是 bbox 居中；相邻拼合色块重叠 0.5–1px 防抗锯齿底缝；inline SVG 加 `display: block` 防基线空隙。

## 视频构图（不是网页排版）

> 本节默认「图解型」写法；当分镜 `presentation_mode` 是其它范式（尤其**文学叙事型**）时，**优先按下方「表达范式」执行细则覆盖本节**（减少图形、改为文字氛围），不要照搬图解型的三层图形要求。

- **每镜至少三层**：背景装饰（光晕 / 网格 / 色块 / 噪点）→ 主体内容（标题 / 卡片 / 数据）→ 前景细节（分隔线 / 标签 / 角标 / 数据条）。
- **每镜至少两个视觉焦点**，让眼睛有地方走；但要有主从（主焦点 + 从属），禁止一个文字块孤零零飘在中间。焦点层级用景深做（见 `skills/camera/SKILL.md`），不要只靠透明度。
- **锚定边缘**：内容靠左/上或靠右/下，居中漂浮是网页习惯。
- **填满画幅**：主标题占画幅宽度 60–80%。
- **分区版式**：优先 zone-based——数据面板左/内容右、顶部元数据条+下方全宽；分区给元素固定「家」，从源头防重叠；居中堆叠是最后手段。**元数据条只放分镜点名要印的内容数据**（时间轴 / 关键数字 / 类别标签）；禁止放镜号、页码、文件名、时长等工程标识，也禁止把 `assets` / `notes` / `motion` / `layout` 里的描述短语印上屏。
- **装饰透明度 12–25%**（低于 10% 在视频里等于没有）；边框 2–4px；内边距 60–140px。
- **背景必须有细节**：径向光晕、细线、网格、噪点、超大字幽灵词、registration-marks、scan-lines、粒子场、色块、纹理——每镜 2–5 个，全片换着用，别每镜一个样。
- 每镜装饰元素都要有缓慢的环境动效（呼吸、漂移、脉冲）；静止的装饰等于没有。
- **前景细节清单**：分隔线、标签、数据条、注册标记、等宽元数据——「produced not generated」；缺前景细节的空壳画面不成立。**标签 / 等宽元数据只能承载分镜点名要印的内容**（`on_screen_text` 或分镜明确语句）；禁止镜号 / 页码 / 文件名 / 时长等工程标识上屏（`SHOT` / `SCENE` / `镜 N` 全禁），也禁止把分镜描述短语（`assets` / `notes` / `motion` / `layout` 里的说明）当成屏上文字。
- **一镜一动 + 分配静止**：星牌 / 标题卡只做一次克制揭示，其余全静止；禁止为填时长制造第二发展阶段——安静镜是全片呼吸点。
- 字号尺度（1920×1080 基准；竖屏 1080 宽放大 10–20%）：

| 元素 | 字号 | 备注 |
| --- | --- | --- |
| 主标题 | 64–120px | 字重 700–900 |
| 正文 | 28–42px | 字重 300–400 |
| 标签 / 数据注 | 18–24px | 可用等宽体、加宽字距 |
| 数据大字 | 120–220px | `tabular-nums` |

- 字重对比要极端（标题 700–900 vs 正文 300–400）；标题字距收紧 `-0.03em ~ -0.05em`。
- 一套字体里不要混两个相似的无衬线；要么同字体两字重，要么衬线 + 无衬线 / 无衬线 + 等宽。
- **标题阶梯**：标题块 ≤78% 画幅宽（≈1497px @1920），按长度降级——≤3 词用最大档、4–6 词用中档、7+ 用最小档；短行放大，长行降档，绝不贴边。
- **可读下限**：承载信息的文字 ≥27px（约 1.4cqw @1920）；px 级的等宽 / 标签只能做装饰性 chrome。
- **阅读时间**：屏上停留 3 秒的文字要能在 2 秒读完——少字、大字，不要整句字幕化。

## 表达范式（先看分镜 `presentation_mode`，按它执行）

分镜每镜都标了 `presentation_mode`；**画面载体必须与它匹配，全片只用一套范式，禁止自行发明画面类型。** 「视频构图」一节默认图解型；其它范式按本小节覆盖。

| 范式 | 主载体 | 允许 | 禁止 |
| --- | --- | --- | --- |
| 图解型（默认） | 卡片 / 路径 / 节点 / 流程 | 机制动画、关系图、步骤推进 | 纯文字氛围片 |
| 数据论证型 | 数字大字 / 对比 / 简单图表 | 计数、柱 / 环、对撞 | 无意义的装饰性数字 |
| 教程步骤型 | 步骤卡 / 编号 / 进度 | 流程推进、编号 stagger | 无编号的抽象堆叠 |
| 列表型 | 枚举卡 / 编号 / 三分法 | 逐条 reveal、均匀节奏 | 无编号的抽象堆叠 |
| **文学叙事型** | **大字排印 / 光影氛围 / 留白** | 位移 / 淡入 / 呼吸 / 光感、简洁道具线稿 | **数据网、时间轴、节点、路径生长、进度条、气泡、星形、拟物人物、复杂物体** |
| 观点论述型 | 大字论断 / 正反对照 / 引用卡 | 论断 punch、双方对照 | 冗余图解 |

**来源可追踪的视觉（所有范式通用）**：画面里的元素必须来自分镜 / 来源自己的意象——来源里的词、物、隐喻（小说的雪 / 茶壶 / 玉佩；讲解对象的术语与关系）。**若一个图形换到别的视频也能原样用，它就没出自来源——换掉，不要套通用模板**（网络图、气泡、星形对任何片都适用，等于没为这一片设计）。

**文学叙事型执行细则**（小说 / 散文 / 情绪片——本小节重点）：

- 载体是**文字**：一句一屏的大字排印 + 氛围光影（光线、雾、纹理、渐变），留白本身就是构图；**不是**把情节翻译成图形。
- 拿得准的单个道具可用**简洁几何 / 单色线稿**（一把茶壶 = 壶身椭圆 + 壶嘴弧线 + 描边），每镜前景图形元素 **≤ 2 个**；**禁止**自绘人物、动物、复杂机械、透视场景。
- 动画限：位移 / 淡入淡出 / 呼吸 / 光晕流动；**禁止**图解式动作（路径生长、节点吸附、数据填充、时间轴展开、进度条）——信息量交给旁白，画面默认克制。
- 背景 1–2 层氛围（雪粒、光柱、渐变、纹理质感），**不是**五角星 / 气泡 / 网格墙 / 随机图案堆。
- 少即是多：宁可静，不要噪。

**画不出的复杂具象（所有范式通用）**：真人脸、复杂机械、细致场景、透视街景——模型画不好，**降级为「大字 + 符号 + 简单几何」**，绝不自绘低质拟物；**画面质量永远高于图形完整度。**

## 讲法落地（分镜标了讲法时按它设计机制；没标就按内容自然选一个）

| 分镜讲法 | 画面机制 |
| --- | --- |
| 类比 / 隐喻 | 两个形象并置，源侧托目标侧，共享同一动势 |
| 渐进揭示 | 同构图逐层叠加：旧层保持、新层亮起，一次只加一层 |
| 正反对照 | 双区对置，一侧升权、一侧降饱和；或整组翻转 |
| 因果链 | 路径 / 箭头逐段生长，节点随因果依次点亮 |
| 演示机制 | 真实 DOM 主体把流程跑一遍，不是静态示意图 |
| 规则三分 | 三栏 / 三卡编号，逐条 reveal |
| 引用 / 出处 | 小字注一条（遵守屏上文字出处纪律），不喧宾夺主 |
| 收口一句 | 多元素向中心收，结论词定格 |

讲法落地同样受表达范式约束：文学叙事型里「因果链」退化为时间先后（无箭头网络）、「演示机制」退化为单个道具的简单动作——先范式，后讲法，再图形。

## 排版细节

- 数据：`font-variant-numeric: tabular-nums`，比率用 `diagonal-fractions`，单位 / 缩写可用 `all-small-caps`；代码用 `font-variant-ligatures: none`。
- 全大写 / 宽字距标签：`letter-spacing 0.08–0.15em`（微标签 0.14em+）。
- 每场只用一个「表达性」字体；不要两个相似无衬线并置；用衬线 + 无衬线、或无衬线 + 等宽切换 register（陈述 / 数据 / 出处）。
- **行高基准**：正文 `line-height 1.6–1.7`（多行文字防叠行 / 疏密不均）；标题收紧 `~1.1` + `max-width` 自然换行，防标题挤占其他层。
- **12 列网格**：元素对齐不可见 12 列网格（@1920 ≈ 160px/列），坐标落网格上，禁止随手漂移定位。
- **单变量对比**：要层级先只改一个变量（同字形等比 vs 等宽、同族不同光学尺寸、只改节奏 / 字重），不靠堆新字体。
- 内置字体白名单里相对有识别度的：`Montserrat` `Oswald` `League Gothic` `Archivo Black` `Space Mono` `IBM Plex Mono` `JetBrains Mono` `Source Code Pro`；`Inter` / `Roboto` / `Poppins` / `Playfair Display` 等是「安全但大众」的选择，靠字号与字重拉开层级。

## 主题消费（配色 / 字体 / 表达包）

本片主题在 `skills/theme/<visual_style>/`：

- `tokens.css` 是唯一的颜色 / 字体 / 圆角 / 动效来源；HTML 里一律 `var(--…)`，**不要写死 hex 或字体名**。
- `theme.json` 的 `guidance` 是本主题的表达包：`fonts` / `composition` / `motion` / `expression`，按它落实卡片、进度、装饰等细节。
- 把 `tokens.css` 的 `:root { … }` 块内联进每个 composition；不要引入 token 之外的新色。

通用底线：一套配色全片不改；accent 全片唯一且承载语义；浅色画布不要转深色；字体只用主题 token 或下方白名单。

## 落盘前自检（脑子里过，不跑命令）

- [ ] 颜色全是 `var(--…)`，无发明 hex；字体只在主题 token 内；
- [ ] 字重符合：标题 700–900 vs 正文 300–400 极端对比（League Gothic / Archivo Black 只用 400）；
- [ ] 正文行高 1.6–1.7、标题 line-height ~1.1；元素对齐 12 列网格；
- [ ] 装饰 12–25% 透明度、2–4px 边框；每镜 ≥2 个背景装饰；
- [ ] 一镜一动：全镜只有一个持续微动元素，其余揭示完即静止。
