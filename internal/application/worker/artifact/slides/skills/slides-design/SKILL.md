# 视觉设计：让它像人做的

本技能是 slides 生成入口提示的知识库（位于工作目录 `skills/slides-design/SKILL.md`）。
**配色 / 字体 / 字号 / 间距 / 圆角全部由 `skills/theme/<visual_style>/theme.json` 固定**（入口提示已把它内联进来）；本文件讲的是在既定 token 里怎么用得好、怎么排版不土。

## 主题 token（唯一来源，禁止自造）

| token | 用途 |
|---|---|
| `palette.primary` | 标题、最深文字 |
| `palette.secondary` | 正文、次级文字 |
| `palette.accent` | 强调（页码、短条、高亮、关键数字、图表主色） |
| `palette.light` | 卡片浅底、浅强调 |
| `palette.bg` | 页面背景 |
| `fonts.cjk` / `fonts.latin` | 中文 / 英文 `fontFace`（备选见 `fonts.latinAlt`） |
| `type.*` | 字号（pt）：`coverTitle` / `sectionTitle` / `pageTitle` / `subtitle` / `body` / `caption` / `statNumber` / `pageNumber` |
| `space.*` | 边距与间距（**相对 PAGE 的比例**）：`marginX` `marginY` `footerH` `gapX` `gapY` `pad` |
| `radius.*` | 圆角（相对卡片短边）：`card`（0 = 用 `RECTANGLE`）、`pill`（= 高度/2） |
| `chart.*` | `colors` / `grid` / `axis` |

用色规则：

- **主导色权重**：一个页面上 `bg` + `primary` 应占 60–70% 视觉重量，`accent` 只占一小块（10–20%），不要把五个颜色平均分配。
- 文字与 `bg` 必须高对比；`cute` 的标题用 `primary`，**不要**用浅粉当正文。
- 颜色只能承载语义（分组、强调、数据系列），不做无意义装饰。透明度用 `transparency`（0–100），禁止 8 位 hex。
- 禁止写死 hex / 字号 / 比例；要改风格就换 `theme.json`，不要在页面代码里微调。

## 风格档（由 `theme.json` 的 `guidance` 描述；整份 PPT 只用一档）

`theme.json` 的 `guidance.composition` / `guidance.typography` / `guidance.expression` 就是本套风格的版式与表达要求，写页时按它执行。三套的性格：

- **educational（锐利科普）**：页边距紧、直角或极小圆角、信息偏密、高对比几何分区，少装饰圆/气泡；
- **cute（圆润可爱）**：留白充足、圆角明显偏大、胶囊页码、轻装饰，不做尖锐报表风；
- **default（柔和平衡）**：中等边距与间距、圆角适中（外容器 ≥ 内层）、均衡留白、温和清晰。

圆角只用 `ROUNDED_RECTANGLE`（`radius.card` 为 0 时用 `RECTANGLE`）；圆角容器**不要**再叠一条矩形色条当顶边（对齐分隔用独立短 `RECTANGLE` 即可）。

## 页型分工（每页仅一种）

| 页型 | 要点 |
|---|---|
| **封面 Cover** | 大标题 + 副标题 + 日期/场合；左右非对称或居中。主标题远大于副标题；位置由"先算后画"的居中/分栏公式得出 |
| **目录 TOC** | 若干章；竖排/双列/侧栏/卡片均可。章节号醒目，编号格式与分隔页一致（01、02…） |
| **章节分隔 Section** | 章节号 + 标题 + 可选短引言；留白充足，与内容页明显区分；全文分隔页样式一致 |
| **内容 Content** | 选一子类：纯文字（**必须**配图标/图形）/ 图文 / 数据可视化（**必须**标来源）/ 对比 / 时间线流程 / 图片展示。每页至少一个非文字元素；**相邻内容页布局不得相同** |
| **总结 Summary** | 要点回顾 / CTA / 联系 / 致谢。收尾语最醒目，语气呼应封面；回顾宜短 |

## 字号层级（一律取 `tokens.type`，禁止自定 pt）

| 用途 | 相对层级 | token |
|---|---|---|
| 注释 / 来源 | 最小 | `type.caption` |
| 正文 | 小 | `type.body` |
| 副标题 | 中 | `type.subtitle` |
| 页标题 | 大（粗体） | `type.pageTitle` |
| 章节分隔标题 | 大（粗体） | `type.sectionTitle` |
| 封面大标题 | 最大（粗体） | `type.coverTitle` |
| 数据强调 | 可大于页标题 | `type.statNumber` |
| 页码 | 最小 | `type.pageNumber` |

对齐：多行说明**左对齐**；卡片内短标签/数字/单行标题可居中。正文与注释**禁止加粗**，加粗只留给标题、章节头、数据大字。

页标题下可用**短 accent 条**（宽度约为标题宽的 10–15%、很薄、与标题左对齐）；**不要**拉通栏细线代替留白。

## 间距与留白

- 页边距 / 页脚带 / 元素间距 / 卡片内边距**全部**取 `tokens.space`（`marginX` `marginY` `footerH` `gapX` `gapY` `pad`），按 `units` 说明乘 `PAGE_W` / `PAGE_H` / 卡片短边——**不要**自己发明比例。
- 同一页只用一档间距，不要随机混用；风格越"松"（cute），`space` 越大。
- 留白是设计的一部分：不要为了"充实"把每一寸都填满。
- 所有间距/边距/圆角都必须写成已算出的 `marginX` / `marginY` / `gapX` / `gapY` / `pad` 的表达式，不要另写一套互不相关的绝对尺寸表。

## 可复用的版式手法

**每页都要有视觉元素**——图形、卡片、图标形状、图表或图片；纯文字页不可接受。备选布局：

- 双栏：文字左 + 图形/示意图右（或反转）
- 图标行：小圆底图标 + 粗体小标题 + 一行说明，纵向 3–4 行
- 2×2 / 2×3 网格：一侧放主视觉，另一侧放内容块矩阵
- 半出血：整块左侧或右侧铺满图片/色块，内容叠在其上（注意对比度）
- 卡片带：横向 2–4 张圆角卡，卡内 = 短标题 + 至多一行副说明

**数据呈现**：

- 大数字 callout：`type.statNumber` 的字号 + 其下小标签（比整段文字有说服力得多）
- 对比列：before/after、方案 A/B 左右并列，用 `palette.light` 底做区分
- 时间线 / 流程：编号节点 + 箭头（`CHEVRON` 或 `LINE` + `OVAL`），横向推进
- 图表：见 `skills/pptxgenjs/SKILL.md`，颜色用 `tokens.chart.colors`，必须设标题/数据标签，并标数据来源

**视觉母题**：选**一个**有辨识度的元素并在每页重复（圆角图片框、彩色圆底图标、统一的卡片圆角与间距），把它贯穿全篇。**不要**用色条/强调条当母题。

## 明暗与节奏

- 封面与总结可用深色底（`primary` 作 `bg`，文字用 `bg` 色反白），中间内容页用浅底，形成"三明治"节奏；或全篇深色做高级感，但必须全篇一致。
- 相邻内容页换版式、换结构；不要每页都是"标题 + 三条要点"。

## 反"AI 味"清单（出现即算不合格）

- **禁止通栏色条**：页眉/页脚横条、沿页面一侧的竖条、卡片单边条、"只有一边有边框"的矩形——一律不要。要区分卡片就用浅底色、阴影或图标。
- **禁止标题下划线/通栏细线**（短 accent 条除外，见上）。
- 不要每页同一版式；不要"标题 + 三条要点"贯穿全篇。
- 不要正文居中；不要低对比图标（深底上的深图标要加对比圆底）。
- 不要纯文字页；不要把所有内容塞进一张卡片。
- 不要字号层级塌陷：页标题必须显著大于正文（取 `tokens.type.pageTitle` / `tokens.type.body`，不要自己缩）。
- 不要用浅色文字叠浅色底；不要让元素离页面边缘小于 `tokens.space.marginX * PAGE_W`。
- 不要乱换间距（同一页只用一个 gap 档）。
- 不要文字溢出容器或被容器裁掉（宁可减字/拆页）。
- 不要留占位符（`xxx`、`lorem`、`TODO`、`待补`、"[插入…]"）。
- 不要把所有页都做成卡片网格：版式要跟着内容走（对比→两栏，流程→时间线，指标→大数字）。
- 不要丢失 `> 备注：` 的内容：它不上页面，但必须进 `slide.addNotes()`（见 `skills/pptxgenjs/SKILL.md`）。
