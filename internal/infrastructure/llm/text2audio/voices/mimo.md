# MiMo — 语音风格控制说明

MiMo TTS 通过 `voice_instruction` 传入自然语言指令控制语气与风格。支持**中文**和**英文**指令。
对于中文播客，`voice_instruction` 请使用中文描述，更贴合中文音色。

## 指令控制（`voice_instruction`）

用自然语言描述语速、情绪、语调、声线特质。不要写空泛词。可组合维度：语速 · 情绪 · 语调 · 角色 · 场景。

```
语速偏慢，语气沉稳，像在讲解一个关键的结论。
语速较快，略微上扬，带着好奇追问的兴奋感。
温暖叙事，语调轻柔平和，像在篝火边讲故事。
严肃清晰，念到数字和对比处时加重，有权威感。
活泼俏皮，末尾微微上扬，像在邀请对方接话。
```

## 写法示例

```json
{
  "text": "模型不是卡在网络里，是卡在注意力层的内存访问模式上了。",
  "voice_instruction": "语速偏慢，语气沉稳有力，在关键术语后稍作停顿，声音像深夜电台DJ一样有磁性。"
}
```

```json
{
  "text": "你可以把它想象成一个图书馆，每一本书都要先看过所有其他书，才能被摆到书架上。",
  "voice_instruction": "温暖、像在讲故事，语速稍慢，末尾语调微微上扬，带一点邀请思考的感觉。"
}
```

```json
{
  "text": "所以两边其实在争同一件事？能不能把分歧收敛到成本上？",
  "voice_instruction": "语速偏快，真诚好奇，末尾上扬，语气略微俏皮。"
}
```

```json
{
  "text": "我们对齐一下：你是说推荐系统的冷启动，本质上是先验分布缺失的问题？",
  "voice_instruction": "语速适中，语气专业性且带追问感，关键词「冷启动」「先验分布」略微加重。"
}
```

## 使用原则

1. 指令写在 `voice_instruction` 字段，用自然语言。
2. 描述要具体：语速/情绪/语调至少一个维度落到实处。
3. `text` 只放对白正文，不要夹带控制标记。
4. 每轮一条指令即可，避免堆砌矛盾要求。
