# 视觉风格与画面质量

本技能是 `video-generate` 入口提示的知识库（位于工作目录 `skills/visual-style/SKILL.md`）。
**设计画面、画示意图、排版前读本文件**。配色表与三套风格块在入口提示里，全片只用那套色盘；本文件讲怎么把它用好看、把示意图画得像。

## 通用规则

- 一套配色 = `bg` + `light` + `primary`/`secondary` + `accent`，**全片不改**；中性色向强调色偏一点，不要死灰。
- 每个镜头至少一个颜色「抓住眼睛」；强调色氛围用 15–25% 透明度，焦点元素全饱和。
- 深色背景不要用全屏线性渐变（H.264 会出色带）；用径向渐变或纯色 + 局部光晕。
- 文字对比度满足 WCAG AA：正文 ≥ 4.5:1，大标题 ≥ 3:1；`cute` 标题用 `primary`，勿用过浅粉当正文。
- 反 AI-slop：渐变文字、左侧彩色竖条、纯黑纯白、一模一样的卡片网格、所有内容居中且权重相同——出现前先确认是有意为之。

## 构图三测（每帧过一遍）

- **Squint 眯眼测**：一个主元素要比最近的次元素大 3–6×；不同时出现两个「标题级」元素（要主从，不要平权）。
- **Silence 留白测**：陈述帧读起来应有 45–60% 的空白；全片只指定**一个「密集例外」帧**（数据 / 机制帧）允许塞满；稀疏帧不要为了显得完整而填满。
- **Restraint 克制测**：稀缺手势每帧只出现一次——一个硬阴影、一档强调色、一种色调处理，不要叠加。
- 每帧写一句 Reference + 失败模式（如「投研简报风；失败 = 扁平、无边框、柔阴影的网页卡片网格」），防止自己漂回默认网页感。

## 图形语义（示意图必须「读得出来」）

没有真实素材时用抽象图形，但抽象图形也必须像它代表的东西——**形状、比例、符号、纹理承担语义**，不要靠颜色硬凑：

| 画什么 | 怎么画 |
| --- | --- |
| 屏幕 / 设备 | 设备比例 + 圆角 + 2–4px 描边 + 极淡扫描线纹理 + 内阴影；描边是信号，填充保持安静 |
| 视频 | 屏幕签名 + 居中圆环里的播放三角 |
| 图片 | 4:3 / 3:2 色块 + 偏角落（不居中）的地平线 + 圆盘符号 |
| 卡片 | 底板 + 1px 描边 + 两条不等长骨架线（100% / 62% 宽） |
| 人 / 头像 | **圆形** + 镂空首字母；多人堆叠用不同明度档，不用不同色相 |
| 品牌 / Logo | **圆角方形** + 镂空标记；一排 Logo 用同一明度档（表示「同等」） |
| 图表 | 平涂柱 / 线；主系列最实、对比系列次之、网格线用 1px 极淡描边；**柱内禁止渐变**（柱越高顶部越浅，会反向误导对比） |
| 文字块 | 圆角横线，宽度 100% / 86% / 62%，右缘参差才像文字 |
| 连线 / 箭头 | 必须能说出起点锚、终点锚和作用（揭示 / 路由 / 验证 / 强调）；说不出就删 |

明度阶梯（用 `primary`（或 `secondary`）的透明度，全片统一）：实心内容 100% → 主体 72% → 支撑 45% → 介质填充 18% → 底板 8%（也可直接用 `light`）；1px 边界用 14%。相邻档至少差 1.6 倍；文字不低于 72% 档，需要比较的图形不低于 45% 档。圆形 = 人，圆角方形 = 品牌 / 应用，两个形状语义不要混。

- 深度不靠阴影靠层级：明度差 → 1px 描边 → 留白 → 细纹理（2–4px 周期，只用于标注「这里是媒体 / 内容」）。阴影必须无彩、扩散：`0 Npx 3Npx rgba(0,0,0,0.18)`；彩色光晕是强调色，不是阴影。
- 强调色全片最多一个元素且必须承载意义（选中的档、当前步骤、计数落点、正在画的描边）；占位图形永不用强调色。
- 禁止无物理意义的占位渐变（紫→蓝、彩虹、斜向色块）；允许的渐变只有：物理表面（设备边框 / 玻璃）、扫光（透明→白→透明）、压暗 / 晕影、以及本身就是主体的效果。
- 本片三套风格都是浅色画布：**不要转深色**；用更粗的描边（2–4px）、结构线、全饱和强调色、极淡纹理避免「空白幻灯片感」。
- 图标用基础几何（圆 / 方 / 线 / 简单 path）画，最小可辨特征 ≥ 24px；不要 emoji 充图标，不要硬凑复杂写实路径。
- **完整性**：分镜里每个具名图形，DOM 里必须真的有它的主体——说「三节点关系」就得有三个节点和连线；说「路径生长」就得有真实路径；说「翻转 / 填充 / 对撞」就得真发生。图形缺失或退化成空盒子，比不好看更严重。

## SVG 绘制纪律（图标 / 示意图）

- **原语优先**：能用 `<circle>` / `<ellipse>` / `<rect rx>` / `<line>` / `<polygon>` 就别用 `<path>`；原语不会走形，只有自由形状才用 path。
- **对称靠镜像**：先定中心与坐标网格（如 `viewBox="0 0 120 120"`、中心 60,60），左右 / 上下坐标成对镜像（左 30 右 90），不要各自估。
- **闭合**：闭合图形用 `<polygon>` 或 path 末尾写 `Z`，不要指望描边端点自己接上。
- **曲线**：圆弧用原语或 `A` 命令，禁止随手写 `C` / `S` 贝塞尔控制点。
- **描边留边**：`stroke-width` 向路径两侧各扩一半，viewBox 四周留 ≥ `stroke-width/2` 边距；出血装饰显式处理（`overflow: visible` 或容器裁切）。
- **比例**：`viewBox` 宽高比必须与显示尺寸一致，别让 CSS `width/height` 拉成不同比例，否则整体拉伸走形。
- **发丝线**：视频里 1px 线会闪 / 消失（H.264），SVG 描边 ≥2px、整数坐标。
- **端点与填充**：`stroke-linecap="round"` / `stroke-linejoin="round"` 避免 miter 尖刺；描边图形必须 `fill="none"`，空心 / 挖洞图形用 `fill-rule="evenodd"`。
- **箭头 marker**：`refX` / `refY` / `orient="auto"` 设对，否则箭头脱离线或飞出去。
- **渐变坐标**：明确 `gradientUnits`（`objectBoundingBox` vs `userSpaceOnUse`），用错位置就偏。
- **缩放保描边**：元素被 `scale` 放大时用 `vector-effect="non-scaling-stroke"` 保持描边粗细。
- **别在 SVG 里排文字**：`<text>` 不换行、字体度量与 HTML 不同，文字用 HTML 覆盖。
- **光学对齐**：不对称图形（播放三角、箭头）按视觉居中，不是 bbox 居中；相邻拼合色块重叠 0.5–1px 防抗锯齿底缝；inline SVG 加 `display: block` 防基线空隙。

## 视频构图（不是网页排版）

- **每镜至少三层**：背景装饰（光晕 / 网格 / 色块 / 噪点）→ 主体内容（标题 / 卡片 / 数据）→ 前景细节（分隔线 / 标签 / 角标 / 数据条）。
- **每镜至少两个视觉焦点**，让眼睛有地方走；但要有主从（主焦点 + 从属），禁止一个文字块孤零零飘在中间。焦点层级用景深做（见 `skills/camera/SKILL.md`），不要只靠透明度。
- **锚定边缘**：内容靠左/上或靠右/下，居中漂浮是网页习惯。
- **填满画幅**：主标题占画幅宽度 60–80%。
- **装饰透明度 12–25%**（低于 10% 在视频里等于没有）；边框 2–4px；内边距 60–140px。
- **背景必须有细节**：径向光晕、细线、网格、噪点，每镜 2–5 个装饰元素。
- 每镜装饰元素都要有缓慢的环境动效（呼吸、漂移、脉冲）；静止的装饰等于没有。
- 字号尺度（1920×1080 基准；竖屏 1080 宽放大 10–20%）：

| 元素 | 字号 | 备注 |
| --- | --- | --- |
| 主标题 | 64–120px | 字重 700–900 |
| 正文 | 28–42px | 字重 300–400 |
| 标签 / 数据注 | 18–24px | 可用等宽体、加宽字距 |
| 数据大字 | 120–220px | `tabular-nums` |

- 字重对比要极端（标题 700–900 vs 正文 300–400）；标题字距收紧 `-0.03em ~ -0.05em`。
- 一套字体里不要混两个相似的无衬线；要么同字体两字重，要么衬线 + 无衬线 / 无衬线 + 等宽。
- **标题阶梯**：标题块 ≤78% 画幅宽（≈1497px @1920），按长度降级——≤3 词用最大档、4–6 词用中档、7+ 用最小档；短行放大，长行降档，绝不贴边。
- **可读下限**：承载信息的文字 ≥27px（约 1.4cqw @1920）；px 级的等宽 / 标签只能做装饰性 chrome。
- **阅读时间**：屏上停留 3 秒的文字要能在 2 秒读完——少字、大字，不要整句字幕化。

## 排版细节

- 数据：`font-variant-numeric: tabular-nums`，比率用 `diagonal-fractions`，单位 / 缩写可用 `all-small-caps`；代码用 `font-variant-ligatures: none`。
- 全大写 / 宽字距标签：`letter-spacing 0.08–0.15em`（微标签 0.14em+）。
- 每场只用一个「表达性」字体；不要两个相似无衬线并置；用衬线 + 无衬线、或无衬线 + 等宽切换 register（陈述 / 数据 / 出处）。
- 内置字体白名单里相对有识别度的：`Montserrat` `Oswald` `League Gothic` `Archivo Black` `Space Mono` `IBM Plex Mono` `JetBrains Mono` `Source Code Pro`；`Inter` / `Roboto` / `Poppins` / `Playfair Display` 等是「安全但大众」的选择，靠字号与字重拉开层级。

## 三套风格表达包（把入口的风格块落到细节）

三套都是浅色画布；只允许映射到入口的五色盘，不加新色；字体只用白名单。

**educational（Sharp & Educational）**
- 卡片：4% accent 淡染底 + 20% accent 的 1.5px 边框 + **无阴影**（直角 0–4px 保持）；柔和是高级感的来源。
- 文字三档：近黑标题 / 中性正文 / 浅三级；accent 只用于 eyebrow、数字、进度、图表。
- 底部 3px 进度条随镜序生长（「听到哪、到哪」）；步骤圆点透明度阶梯 1.0 → 0.85 → 0.7 → 0.55。
- 网格纸：~2cqw 单元、accent 10%、2–4px 线（防 H.264 摩尔纹）；装饰环只在封面 / 结尾。

**cute（Rounded & Cute）**
- 所有容器药丸化（小元素 9999px，大卡片 20–32px 圆角）+ 2px 描边；描边色用 `primary`。
- 硬偏移阴影 `6/4px` 零模糊（只给内容元素，漂浮装饰不投影）；半径 20 / 28 / 50px。
- 内联 SVG 小装饰 3–7 个（花 / 星 / 云 / 彩虹，可出血到画框外），禁 emoji；点状 bullet 用描边圆点。
- 强调用药丸高亮（替代加粗 / 斜体）；accent 只做小标记，不做大面积底。

**default（Soft & Balanced）**
- 暖米底 + tile 半阶面（`light` 低透明或 `primary` 淡染）；一帧只有一个 accent 电压（CTA / 链接 / 整条色带，不同时两个）。
- 发丝级 elevation：1px 12% 墨描边 + 至多一个暖阴影；`✱` 做区域 kicker。
- 数字 = serif 数字 + mono 单位；一个 sun bloom（42–70% 画幅、偏心）+ 对角 ember counter-bloom（15–22%）；1px 发丝线是唯一边框；右下角页码。
